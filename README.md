# HunterForge

**Monster Hunter Wilds build & skill calculators** - a static site for hunters who want their numbers
sourced, dated and honest.

Live at **[hunterforge.top](https://hunterforge.top)**

## Tools

| Tool | What it does |
| --- | --- |
| **Armor Set Builder** (`/builder`) | Equip 5 high-rank pieces + charm, search armor by skill, fit armor decorations per slot, and read the aggregated skill table with level caps, wasted-level warnings, set bonus (2/4-piece) and group skill (3-piece) tracking, defense/resistance totals and a crafting materials shopping list. Builds persist in the browser and are shareable by URL. |
| **Decoration Planner** (`/decorations`) | Which jewels grant a skill and what slot levels they need; a farm planner that turns a target skill list into an exact jewel list with slot budget; a filterable browser of all 361 decorations. |
| **Effective Raw Calculator** (`/eraw`) | `ERaw = Raw × (1 + Affinity × CritBonus) × Sharpness`, step-by-step, with Critical Boost Lv0–5, negative-affinity handling, all seven sharpness tiers compared, and the multiplier table cited. Scoped to weapon quality - motion values/hitzones are deliberately out of scope and the page says so. |
| **Skill Library** (`/skills`) | All 179 skills with max caps and per-level effects, linked to pre-filtered builder searches. |
| **Reference & trust pages** | FAQ (`/faq`), Data Sources & Methodology (`/about`), Privacy (`/privacy`), Terms (`/terms`), Changelog (`/changelog`), HTML site map (`/sitemap`), custom 404. |

## Data policy (the site's selling point)

- **Snapshot, dated**: every page shows the data snapshot date (`2026-10-11`) and coverage counts.
- **Sourced**: armor/skills/decorations/charms come from [wilds.mhdb.io](https://wilds.mhdb.io/en)
  (game-file-extracted DB by [LartTyler](https://github.com/LartTyler/mhdb-wilds)); sharpness multipliers
  are hand-verified against Fextralife and community sources (cited on `/eraw` and `/about`).
- **Gaps are flagged, never hidden**: low-rank armor excluded, deco crafting materials missing upstream,
  elemental blue sharpness disputed - all stated in the UI.

## Project structure

```
astro.config.mjs         site URL + sitemap
scripts/
  fetch-data.mjs         downloads mhdb snapshots into data-raw/
  generate-data.mjs      validates + emits src/data/*.ts (AUTO-GENERATED)
  generate-og.mjs        renders public/og.png from SVG (sharp)
src/
  data/                  generated datasets + hand-written sharpness/sources/types/lookup
  lib/                   math: build aggregation, ERaw, deco planning, URL codec
  scripts/               client-side TS per tool page
  pages/                 .astro pages (index, builder, decorations, eraw, skills, faq, about, 404)
  styles/global.css      jungle-expedition theme (deep green / bone / ember)
src/**/*.test.ts         41 Vitest tests: math + dataset integrity
public/                  favicon, robots.txt, _headers (Cloudflare), og.png
```

## Commands

```bash
npm install
npm run dev            # local dev server
npm test               # vitest (math + data integrity)
npm run build          # static build into dist/
npm run preview        # serve the built site

# data pipeline (refresh the snapshot)
npm run data:fetch
npm run data:generate  # re-emits src/data/* - regenerates meta counts
```

## Deploying to Cloudflare Pages

The site is fully static (`output: 'static'`, no SSR, no server code):

1. Push this folder to a Git repository.
2. In Cloudflare → Workers & Pages → Create → Pages → Connect to Git, pick the repo.
3. Build settings:
 - **Framework preset**: Astro (or manual)
 - **Build command**: `npm run build`
 - **Build output directory**: `dist`
 - **Node version**: set `NODE_VERSION=22` env var (a `.nvmrc` is included).
4. Add the custom domain `hunterforge.top` in the Pages project settings.

`public/_headers` ships cache rules for hashed assets plus basic security headers.
Astro emits `404.html`, which Cloudflare Pages serves automatically for missing routes.
The sitemap is generated by `@astrojs/sitemap` at `/sitemap-index.xml` and referenced from `robots.txt`.

## Testing

`npm test` runs the suite that pins the site's math to known values:

- Skill aggregation: caps, waste counting, set bonus activation at 2/4 pieces, group skills pooling
  across sets by name, deco placement rules.
- ERaw: hand-computed cases (including negative affinity and Critical Boost Lv5) and the full
  sharpness multiplier table.
- Decoration planning: farm plans, shortfall reporting, slot budgets.
- URL state: round-trips, malformed links, unknown-id tolerance.
- Dataset integrity: referential checks between all generated files and the published coverage counts.
